# Skill — create-adr

Como registrar uma decisão arquitetural.

1. Copiar o template abaixo para `docs/adr/NNNN-slug-curto.md` (NNNN sequencial).
2. Preencher **Contexto** (o problema, não a solução), **Decisão** (uma frase direta),
   **Consequências** (prós E contras) e **Alternativas rejeitadas** (com o porquê).
3. Decisões que afetam dinheiro, segurança ou contratos públicos exigem aprovação humana
   registrada no PR antes de implementar.

```markdown
# ADR-NNNN — Título

**Status:** proposto | aceito | substituído por ADR-XXXX · **Data:** AAAA-MM-DD

## Contexto
## Decisão
## Consequências
## Alternativas rejeitadas
```
